# Subhi Muhshieh Portfolio

A personal portfolio website for Subhi Muhshieh, built as a responsive static site with HTML, CSS, and JavaScript. The site presents professional background, experience, skills, education, and contact information in a modern, clean layout.

## Live Site

https://subhi-muhshieh.github.io

## Overview

This project is a one-page portfolio designed to showcase:

- professional and academic background
- work experience and training
- selected projects
- technical skills
- education history
- contact information

The site is optimized for desktop, tablet, and mobile screens and is designed to be easy to maintain and update.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages for deployment

## Project Structure

```text
.
├── index.html
├── styles.css

├── README.md
```

## Files

### index.html
Contains the full page structure including:
- header/navigation
- hero section
- about section
- experience timeline
- project cards
- skills grid
- education cards
- contact footer

### styles.css
Defines the visual design and responsiveness of the site, including:
- layout and spacing
- typography
- color palette
- card components
- responsive breakpoints for mobile/tablet

### script.js
Contains small front-end behaviors, utilities, and page interactions if needed.

## Local Development

You can preview the site locally by opening `index.html` directly in a browser, or by serving the project with a local static server.

### Option 1: Open directly
```bash
open index.html
```

### Option 2: Use a local server
```bash
python3 -m http.server 8000
```

Then visit:
```text
http://localhost:8000
```

## Deployment

This project is configured for GitHub Pages.

To deploy:
1. Push the repository to GitHub.
2. In the repository settings, enable GitHub Pages.
3. Select the branch to publish (usually `main`).
4. GitHub Pages will generate the live site URL.

## Customization

To update the portfolio content:

- edit the text in `index.html`
- update colors, spacing, and layout in `styles.css`
- modify any interactive behavior in `script.js`

## Notes

This is a static personal portfolio and is intentionally lightweight, fast, and easy to maintain. It is a good fit for showcasing portfolio content without requiring a framework or backend.
