# Subhi Muhshieh Portfolio

A responsive personal portfolio website for Subhi Muhshieh, built with plain HTML, CSS, and JavaScript. The site showcases his academic background, professional experience, projects, technical skills, and contact details in a clean, modern single-page layout.

## Live Demo

https://subhi-muhshieh.github.io

## Overview

This repository hosts a lightweight static portfolio designed to:

- present professional and academic experience
- highlight selected projects and achievements
- showcase technical skills and areas of interest
- provide an easy-to-maintain personal landing page
- deploy seamlessly via GitHub Pages

## Features

- responsive single-page layout
- clean portfolio sections for About, Experience, Projects, Skills, and Contact
- modern styling with a focused visual identity
- lightweight static implementation with no framework required
- mobile-friendly design for desktop, tablet, and phone screens

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Files

### index.html
Contains the full page structure, including the hero section, about section, experience timeline, projects, skills grid, education, and footer.

### styles.css
Defines the visual design, layout, spacing, typography, colors, and responsive breakpoints.

### script.js
Contains lightweight front-end interactions and any small UI enhancements used by the site.

## Local Development

You can open the site locally in a browser or run a tiny local web server.

### Option 1: Open directly

```bash
open index.html
```

### Option 2: Run a local static server

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This project is set up for GitHub Pages.

To publish it:

1. Push the repository to GitHub.
2. Open the repository settings.
3. Enable GitHub Pages.
4. Select the branch to publish (usually `main`).
5. GitHub Pages will generate the live site URL.

## Customization

To update the portfolio content:

- edit text and sections in `index.html`
- modify styling and layout in `styles.css`
- adjust scripts or interactions in `script.js`

## Notes

This is a static personal portfolio intended to stay simple, fast, and easy to maintain. It is optimized for clarity and readability while remaining lightweight enough for GitHub Pages hosting.
